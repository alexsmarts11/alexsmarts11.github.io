Что такое Multipath TCP?

Multipath TCP (MPTCP) — это расширение стандартного протокола TCP, которое позволяет установить TCP-соединение одновременно по нескольким сетевым путям (интерфейсам). В то время как традиционный TCP ограничивается одним IP-адресом источника и одним IP-адресом назначения, MPTCP может агрегировать несколько подпотоков (subflows).

Это решает фундаментальную проблему современного интернета: устройства (особенно мобильные) часто имеют несколько сетевых интерфейсов (например, Wi-Fi и 5G), но стандартный TCP использует только один из них. Если этот интерфейс теряет связь, соединение обрывается.

Архитектура и принцип работы

MPTCP вводит новый уровень абстракции между приложением и сетью. Соединение MPTCP состоит из нескольких обычных TCP-соединений, называемых подпотоками (subflows).

Ключевые концепции:

  • Data Sequence Space (DSS): MPTCP использует глобальное пространство последовательностей на уровне соединения, чтобы гарантировать, что данные, приходящие по разным путям с разной задержкой, будут корректно собраны в правильном порядке для приложения.
  • Subflow Mapping: Каждый подпоток имеет свое собственное пространство последовательностей TCP, которое маппится на глобальное пространство DSS.
  • MP_CAPABLE и MP_JOIN: Специальные TCP-опции, используемые для согласования поддержки MPTCP при установке соединения и для добавления новых подпотоков.
  • Fallback: Если сервер или промежуточное устройство (например, NAT или фаервол) не поддерживает MPTCP, протокол автоматически и прозрачно откатывается к обычному TCP.
# Пример проверки поддержки MPTCP в Linux
$ mptcpize run curl https://mptcp.dev
# Или проверка через ss (socket statistics)
$ ss -tMnp

Преимущества MPTCP

📈 Увеличение пропускной способности

Агрегация каналов (например, Wi-Fi + Ethernet или 4G + 5G) позволяет достичь суммарной скорости передачи данных, превышающей возможности одного интерфейса.

🛡️ Отказоустойчивость

Если один из сетевых путей выходит из строя или теряет пакет, MPTCP мгновенно перенаправляет трафик через оставшиеся активные подпотоки без разрыва соединения.

📱 Бесшовная мобильность

Устройство может переключаться между сетями (например, с Wi-Fi на сотовую сеть при выходе из дома) без потери сессии и изменения IP-адреса на уровне приложения.

⚖️ Балансировка нагрузки

Трафик динамически распределяется между доступными путями в зависимости от их текущей загруженности, задержки (RTT) и доступной полосы пропускания.

Сценарии применения

  • Мобильные устройства: Apple использует MPTCP (под названием "Multipath TCP") в iOS для Siri и FaceTime, чтобы обеспечить стабильный звонок при переходе из зоны Wi-Fi в зону LTE/5G.
  • Центры обработки данных (Data Centers): Серверы с множественными сетевыми интерфейсами (NIC) используют MPTCP для увеличения пропускной способности "сеал-спайн" (spine-leaf) сетей и отказоустойчивости.
  • Транспорт и IoT: Поезда, автомобили и удаленные устройства, которые постоянно перемещаются между зонами покрытия разных базовых станций или Wi-Fi точек.
  • Резервирование каналов связи: Корпоративные маршрутизаторы, использующие MPTCP для объединения DSL, 4G и спутниковых каналов в один надежный туннель.

Поддержка в операционных системах

Экосистема MPTCP прошла долгий путь от сторонних патчей до нативной поддержки в ядрах ведущих ОС.

  • Linux: Начиная с ядра 5.6 (март 2020), MPTCP поддерживается нативно (upstream). В ядрах 6.x функциональность значительно расширена (поддержка UDP-инкапсуляции, улучшенные алгоритмы scheduler'ов).
  • Apple iOS / macOS: Apple была одним из пионеров внедрения MPTCP. Поддержка присутствует в iOS (начиная с iOS 11 для Siri) и macOS, хотя реализация имеет проприетарные модификации.
  • Windows: Microsoft активно работает над внедрением MPTCP. Экспериментальная и частичная поддержка появляется в последних сборках Windows 11, а также используется в специфичных корпоративных сценариях.
  • Android: Поддержка зависит от версии ядра и вендора. Начиная с новых версий Android, использующих ядра Linux 5.10+, нативная поддержка MPTCP становится доступной.
