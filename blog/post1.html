Нативная поддержка MPTCP в Linux

Начиная с ядра 5.6, MPTCP поддерживается в Linux нативно. Это позволяет использовать несколько интерфейсов (например, Wi-Fi и Ethernet) для одного TCP-соединения.

Для проверки поддержки можно использовать утилиту mptcpize или команду ss -tMnp.
